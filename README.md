# 코코포리아 로그 EPUB 변환기

코코포리아(ccfolia)에서 내보낸 채팅 로그 HTML을 브라우저 안에서 EPUB으로 바꿔 주는 정적 웹 페이지입니다.
서버로 파일을 보내지 않고 전부 브라우저에서 처리합니다.

## 사용법

1. `index.html`을 브라우저로 열거나, 폴더째 정적 호스팅(Vercel, GitHub Pages 등)에 올립니다.
2. 코코포리아 룸에서 내보낸 로그를 업로드합니다. HTML(전체 로그 `[すべて]` 파일 권장, 개별 탭 파일·구형 형식 지원)과 JSON(`룸이름_log.json`) 모두 됩니다. JSON은 파일 이름에서 책 제목을 가져오고, 기본 탭 id(main/other/info)는 메인/잡담/정보로 표시합니다.
3. 옵션을 조정하며 오른쪽 미리보기로 확인합니다.
   - 아이콘 이미지 표시
   - 발언자 통합 (하위 옵션: 아이콘이 바뀌면 분리)
   - 탭 별 구분 (끄면 시간순으로 섞어서 `[탭명]` 표시)
   - 포함할 탭 선택 (예: 잡담 탭 해제)
   - 탭별 `Aa` 버튼: 켜면 그 탭은 작고 회색인 글씨로, 아이콘 없이, 연속 발언을 합쳐서 표시됩니다(전역 옵션과 무관). 코코포리아 기본 잡담 탭은 처음부터 켜져 있습니다. 발언자 이름 옆의 `[탭명]` 표시는 없습니다.
   - 표지: 이미지를 올리면 1000×1600(5:8, 일반 이북 표지 비율) JPEG로 변환합니다. 채우기(가장자리 잘라냄)와 맞추기(여백 채움) 중 고를 수 있고, 좌우 위치 슬라이더로 어느 쪽을 남길지 조정할 수 있으며, 이미지가 없으면 제목·저자로 표지를 자동 생성합니다.
4. 상단의 `EPUB 다운로드`를 누릅니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 마크업 |
| `style.css` | 다크 테마 UI |
| `js/parser.js` | 로그 HTML → 데이터 (신형/구형 형식 자동 감지) |
| `js/layout.js` | 옵션을 적용해 미리보기·EPUB 공용 블록 생성 |
| `js/cover.js` | 표지 이미지 변환·자동 생성 (canvas) |
| `js/epub.js` | EPUB 3 생성 (JSZip 사용, cdnjs에서 로드) |
| `js/app.js` | 상태·이벤트·미리보기·다운로드 |

EPUB은 목차 없이 한 흐름으로 이어지며, 뷰어 성능을 위해 본문을 내부적으로 여러 XHTML 파일로 나눕니다.

## 로컬 미리보기

`.claude/launch.json`에 PowerShell 정적 서버(`.claude/serve.ps1`, 5173 포트)가 등록되어 있습니다. 직접 실행하려면:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/serve.ps1 -Port 5173
```
